Document scanning and processing.

![Docutopus logo](resources/logo.png)


# Instalación y ejecución

Para ejecutar el programa es necesario crear un entorno virtual de python e instalar las dependencias del fichero ```requirements.txt```.

```bash
pip install -r requirements.txt

```
Tras instalar las dependencias se ejecuta el programa con el intérprete de python del entorno virtual.
```bash
python main.py
```
